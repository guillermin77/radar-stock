# 🛒 RADAR STOCK
Aplicación web y móvil de administración interna y control de inventario para pequeños comercios y almacenes de barrio.

## 📌 Objetivos del Proyecto
- **Control de mermas por caducidad:** Alertas tempranas de productos próximos a vencer.
- **Agilidad en mostrador:** Módulo de ventas de salida rápida de pocos clics.
- **Mitigación del desabastecimiento:** Prevención de quiebres de stock en horarios de alta demanda.

## 🛠️ Tecnologías Utilizadas
- **Frontend / Móvil:** Android Studio / React
- **Backend:** PHP / MySQL
- **Entorno:** Visual Studio Code / Hostinger Cloud
